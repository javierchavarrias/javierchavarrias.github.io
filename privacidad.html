Política de privacidad de Atalaya local

Última actualización: 15 de noviembre de 2026.

Quién usa la aplicación

Atalaya local es una herramienta de uso personal. Su único usuario es su autor, que la usa con sus propias cuentas de Google. No se ofrece a terceros.

Qué datos de Google lee y para qué

Con el permiso que el usuario concede en la pantalla de Google, la aplicación lee correos de Gmail, eventos de Google Calendar y archivos de Google Drive y Google Docs. Los usa solo para mostrar al propio usuario su agenda, sus tareas y su correo pendiente, y para preparar borradores de correo que el usuario revisa y envía él mismo. La aplicación no envía correos por su cuenta.

Dónde se guardan

Los datos se guardan en una base de datos local en el Mac del usuario. Las claves de acceso se guardan en el llavero de macOS. No hay servidores propios ni copias en la nube gestionadas por la aplicación.

Con quién se comparten

Los datos no se venden, no se ceden a terceros y no se usan para publicidad. Para algunas funciones (resúmenes, borradores, planificación), el usuario puede pedir que se procesen con servicios de inteligencia artificial que él mismo tiene contratados. Ese procesamiento sirve únicamente para darle esas funciones y no se usa para entrenar modelos generales.

El uso que hace Atalaya local de la información recibida de las API de Google cumple la Política de datos de usuario de los servicios de API de Google, incluidos los requisitos de uso limitado.

Cómo retirar el acceso

El usuario puede retirar el acceso en cualquier momento desde myaccount.google.com/permissions y borrar la base de datos local de su Mac.

Contacto

Para cualquier consulta, escribe al correo de asistencia que aparece en la pantalla de permisos de Google de esta aplicación.
