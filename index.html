Atalaya local

Atalaya local es una aplicación personal para macOS que usa una sola persona, su autor, para organizar su propio trabajo. No se distribuye ni está disponible para otros usuarios.

La aplicación lee el correo, el calendario y los documentos de las cuentas de Google de su autor para mostrarle en su Mac una agenda unificada, una lista de tareas y propuestas de planificación semanal. También puede preparar borradores de correo, que nunca se envían solos: el autor los revisa y los envía él mismo desde Gmail.

Todos los datos se guardan en una base de datos local dentro del propio Mac.
